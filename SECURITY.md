# Security policy

## Supported versions

Security fixes are provided for the latest published PowerContract release.

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Send a private report to:

```text
support@sidelobe.dev
```

Use a subject such as:

```text
PowerContract security report
```

Include:

- the affected PowerContract version;
- a short description of the issue;
- steps to reproduce it;
- the impact you believe it has;
- any suggested fix, if you have one.

Please avoid including credentials, private waveform data, or other unrelated sensitive information.

Ordinary parser bugs, incorrect measurements, and unsupported capture formats should use the public issue tracker unless they create a security impact.
